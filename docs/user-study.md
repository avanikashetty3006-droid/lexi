# User study
The full protocol, tasks and scoring are in `evaluation/study/protocol.md`.
Raw responses go in `evaluation/study/responses.csv` (use P01, P02, ... never names).
Results appear in the dashboard (section 7) and must be copied into `docs/report.md` section 8.

Checklist before the first participant:
- [ ] Backend running with the same model as the evaluation
- [ ] Frontend running with `VITE_USE_MOCK=false`
- [ ] 12 task cards printed (6 per version, 2 clean tasks per version)
- [ ] Counterbalanced order sheet (half start with Lexi, half with the baseline)
- [ ] SUS and NASA-TLX forms ready
